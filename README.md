# 🧠 Hybrid RAG Agent — Personal Knowledge Assistant

A Retrieval-Augmented Generation (RAG) system with **agentic tool-use**: it searches your own documents first, and automatically falls back to live web search when the answer isn't found locally.

Built to explore how retrieval, embeddings, and LLM tool-calling combine into a single reasoning pipeline — not just a static Q&A bot.

---

## What It Does

Ask a question. The agent decides, on its own, whether to:
1. **Search your personal documents** (via a Chroma vector index), or
2. **Search the web** (via DuckDuckGo), if the documents don't have the answer

The final answer is generated by an LLM (Groq), grounded in whichever source was used — with **inline numbered citations** `[1] [2]` so you always know where the answer came from.

## Architecture

```
User Question
      │
      ▼
┌─────────────┐
│   Agent     │  (Groq LLM with tool-calling)
│  (decides)  │
└──────┬──────┘
       │
   ┌───┴────────────────┐
   ▼                    ▼
┌─────────────┐   ┌─────────────┐
│  search_    │   │  web_search │
│  documents  │   │  (DuckDuckGo)│
│  (Chroma)   │   └─────────────┘
└─────────────┘
       │
       ▼
  Grounded Answer + Sources
```

### Ingestion Pipeline (offline, one-time)
```
PDFs → Load (PyPDFLoader) → Chunk (RecursiveCharacterTextSplitter)
     → Embed (all-MiniLM-L6-v2) → Store (Chroma)
```

## Tech Stack

| Component | Choice | Why |
|---|---|---|
| LLM | Groq (`openai/gpt-oss-20b`) | Free tier, very low latency |
| Embeddings | `sentence-transformers/all-MiniLM-L6-v2` | Free, local, fast (384-dim) |
| Vector DB | Chroma | Simple, file-based, good for small-medium scale |
| Orchestration | LangChain (LCEL + tool-calling) | Composable retrieval + agent logic |
| Web Search | DuckDuckGo (`ddgs`) | No API key required |
| UI | Streamlit | Fast to build, good for demos |

---

## Key Design Decisions

- **Chunking**: 1000-character chunks with 150-character overlap, using a recursive splitter that respects paragraph/sentence boundaries before falling back to hard character cuts — this avoids splitting a sentence mid-thought across two chunks.
- **Hallucination prevention**: The system prompt explicitly instructs the model to say *"I don't have enough information"* rather than guess, when retrieved context doesn't contain the answer. Verified working — see example below.
- **Agentic fallback**: Rather than a fixed retrieval pipeline, the LLM itself decides (via tool-calling) whether the personal knowledge base is sufficient, or whether to search the web — this generalizes beyond the ingested documents.

**Example (hallucination check):**
```
Q: What is the capital of Australia?
A: I don't have enough information in my documents to answer this.
   [Agent correctly avoided guessing from irrelevant retrieved chunks]
```

## Running Locally

```bash
# 1. Clone the repo
git clone https://github.com/akashkashyap000/Hybrid-RAG-Agent.git
cd Hybrid-RAG-Agent

# 2. Install dependencies
pip install -r requirements.txt

# 3. Add your Groq API key
echo "GROQ_API_KEY=your_key_here" > .env

# 4. Run the app
streamlit run App.py
```

Get a free Groq API key at [console.groq.com](https://console.groq.com).
